# えぃにめ一閃流奥義「一閃」

## Windows ユーザー向け TL;DR

- 一閃流とは、アニメのスクショを撮って Discord に投げる営みを保証する Windows 用 GUI ツールである
- DL は [release](https://github.com/Nu-Pan/aynime_issen_style/releases) へ
- 使い方は [wiki](https://github.com/Nu-Pan/aynime_issen_style/wiki/User's-Manual) へ

## macOS ユーザー向け TL;DR

- macOS 版フォークがあるからそっちを使ってね [chikuwav/aynime_issen_style_mac](https://github.com/chikuwav/aynime_issen_style_mac)

## 開発者向け TL;DR

### 開発環境セットアップ方法

環境

- windows + vscode
- python+ctk 製

手順

+ vscode で aynime_issen_style.code-workspace を開く
+ 仮想環境を新規作成
    - コマンドパレット（Ctrl+Shift+P）から「Python: Create Environment」
    - Venv を選択
    - システムの python を選択 

### 実行方法

- 「App」構成でデバッグ実行（F5）

### 実行可能ファイルビルド方法

- 「Build」構成でデバッグ実行（F5）
